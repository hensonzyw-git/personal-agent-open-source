# Git 历史与隐私

本仓库保留私人开发项目的 Git 提交顺序、作者及提交者时间，以及提交之间的父子关系。公开前清理了私人证据、真实 Finance 表达、配置与部署标识，并调整了部分提交说明和作者邮箱。因此公开 commit ID 与私人仓库不同；旧签名不继承。清理私人内容后变空的提交保留为时间线节点。

公开版在这条历史之后，按实际准备时间添加 MIT 许可、架构说明、部署示例和明确标注的合成评测集。原始评测结果和私人验收回执不随历史发布。历史提交可以展示开发过程，但 Git 日期可由提交者设置，不能单独作为不可篡改的时间证明。各旧版本也不保证能以公开版配置独立部署。

[公开 Finance 评测数据说明](./FINANCE_EVALUATION_DATA.md)和[当前离线验证结果](../verification.md)分别记录数据来源及本次候选的验证范围。

第二轮公开前检查又替换了一条带线上缺陷线索的合成旅行案例及个人化部署账号、SSH 密钥文件名，并将替换覆盖到保留历史。本地改写保留提交图、作者／提交者身份和时间；新的提交 ID 与首次公开候选不同。旧克隆、备份和远端缓存可能仍持有旧对象，不应再把它们推回公开仓库。公开前仍需核对远端实际引用及仓库可见性；详见验证说明。
