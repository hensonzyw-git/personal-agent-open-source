## 文档边界

**本套导读与 README 一起发布，不依赖访问作者的私有仓库。** 其中源码相对链接按原项目目录结构组织，指向公开仓库应保留的实现；它们不是安装步骤。

少量原始 PRD、ADR、gate 与历史证据仅保留为路径线索，不设为必读前置条件。这些原文件不包含在本次文档包内；是否随代码公开，由逐份脱敏和整理结果决定。

公开源码取自截至 2026-09-23 的固定私人开发基线；历史 2026-09-17 实测不自动覆盖新增代码。既有实现、有限实测、待验收与规划分开记录。

## 维护原则

README 保留定位与概览，详细说明只在对应专题维护。功能状态变更先更新[能力文档](./capabilities.md)，再更新首页摘要；架构变化同步对应源码入口。路线图的建议不自动成为已批准的实现任务。

新增公开仓库不能覆盖项目原始开发时间；更新 Muse 对比时记录核对日期和官方出处，不把“未在资料中确认”写成“不具备”。原始文档被删除、移动或脱敏改名后，应同步检查源码与文档链接。
