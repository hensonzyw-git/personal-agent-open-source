# 公开快照验证

**语言 / Language：** [简体中文](./verification.md) · [English](./verification.en.md)

本快照分享代码与架构，不提供可直接部署的环境。历史私人环境验收不等于本快照验证。

## 离线检查入口

需要 Python 3.12、uv、Git；Swift 包需要兼容 Swift 6 的 macOS 工具链。
先安装锁定依赖：`uv sync --locked --extra adk`。测试前应使用独立 HOME、清空个人凭据环境，
在操作系统层限制私人文件读取及非本地网络访问。虚拟环境本身不提供这一隔离。

- Python：`.venv/bin/python -m pytest tests/`
- DAL 合同：`.venv/bin/python -m pytest tests/dal/test_registry_manifest_resolution.py tests/dal/test_wave3_artifact_receipts.py`
- Swift：`swift test --package-path ios/PersonalAgentKit`
- 打包：`uv build --no-sources`，然后在独立环境验证 wheel 的资源和导入。

不要运行 deploy 脚本或 live/provider 探针来验证本地导出。这些入口需要额外授权和自备环境。

Gitleaks v8.30.1 的历史 diff 扫描有 2,575 条规则命中：2,544 条位于冻结合同中的 `idempotency_key` 测试值，其余 31 条分布在测试、夹具、源码／测试向量及生成器中。其中一条 `private-key` 命中来自测试在运行时构造 PEM 的代码；设备认证向量明确标注其私钥只用于跨语言测试。未发现已确认的生产凭据，但规则扫描不替代人工隐私检查。

较早候选上的完整 Python 套件停滞、30 个沙箱相关失败节点，以及 Swift 语音回调崩溃尚未在本次公开候选上关闭。本候选是源码与架构的参考发布，不应描述为完整部署或真机验收通过。

## 第二轮公开前隐私复核（2026-09-23，本地候选）

复核发现 `TRV-005` 虽标为合成，却带有具体线上缺陷来源标签及事件细节。本轮保留旅行期间交通费用分类的测试目的，重新虚构输入表达、城市、日期和金额；同时替换相关测试及提示词示例。合成案例若声明真实、线上或私人来源，来源校验现在会拒绝。73 条公开案例仍为 72 条合成与 1 条 PRD 示例；逐条检查标签，已无带 `live` 的标签。与私人基线中 20 条已标为真实表达的输入做规范化精确比较，公开集为零匹配；但 52 条公开案例沿用私人基线里原本标为合成的案例，机器比较不能独立证明它们的创作来源。

部署脚本中的个人化登录账号及 SSH 密钥文件名改为可配置的 `DEPLOY_USER`、`ECS_HOST`、`ECS_SSH_KEY`，示例账号为 `deploy`。上述样本与标识已覆盖到本地保留的历史；尚未推送到 GitHub。第二轮改写前共有 945 个提交、44 个合并节点。逐提交比对后，父子关系、作者与提交者身份及时间的差异均为零。对改写后全部可达对象做已知残留的精确扫描，目标样本、旧来源标签、旧城市／时间、个人部署标识均为零匹配。这是针对已知标记的证据，不是全仓个人信息不存在的证明。

Gitleaks v8.30.1 对改写后的完整可达历史仍报告 2,575 条规则命中。逐条读取历史位置后，2,544 条都位于六份冻结合同的 `idempotency_key` 行；其余 31 条为测试、夹具、测试向量、源码类型／哈希及生成器相关命中，包含一条在测试运行时生成 PEM 的代码。没有确认到生产凭据。`.gitleaksignore` 只登记这些已核实命中的精确 fingerprint，不按目录或规则整体忽略；本地复扫未解释命中为零。CI 增加了完整历史扫描，但本地结果不代表 CI 已通过。wheel 和 sdist 均重新构建，两包中的 Finance 数据与源码逐字节一致，已知残留匹配为零。历史改写后 14 份 DAL 机器合同回执重新绑定，独立回执验证通过。
